# 基于 SAC + HER 的机械臂目标操作与鲁棒控制

我的第一个机器人学习算法复现与改进项目。

## 一、项目简介

本项目基于开源机器人仿真环境 **panda-gym** 和强化学习框架 **Stable-Baselines3**，研究 SAC（Soft Actor-Critic）算法与 HER（Hindsight Experience Replay，事后经验回放）在机械臂目标操作任务中的应用。

项目采用 **GitHub 开源复现 → 核心源码理解 → 算法训练与评估 → 自主改进与实验验证** 的学习路线，逐步掌握机器人强化学习算法的完整开发流程。

## 二、项目目标

- 复现 SAC 算法在机械臂目标到达任务中的训练过程。
- 理解机器人强化学习中的状态空间、动作空间、奖励函数和环境交互机制。
- 掌握 SAC 的 Actor-Critic 结构、经验回放及网络更新原理。
- 复现 SAC + HER，理解目标重标记机制及其在稀疏奖励任务中的作用。
- 建立标准化的模型训练、评估与实验记录流程。
- 尝试改进训练策略，并分析机械臂控制策略的鲁棒性与泛化能力。
